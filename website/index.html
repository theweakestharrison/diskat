    Safety

    Your files don't have nine lives.

    So Diskat treats every delete like it matters. These are always locked:

    C:\ C:\Windows Program Files ProgramData C:\Users\* AppData
    • Recycle Bin first. Del moves things to the Recycle Bin. Permanent delete needs Shift+Del and a dialog that defaults to Cancel.
    • Links are never followed. Junctions and symlinks are shown but never walked through, so nothing is counted twice or deleted by accident.
    • Tricky names are refused. Names ending in a dot or space make Windows touch a different item, so Diskat won't delete them.
    • Honest numbers. If a folder wasn't fully scanned, the delete dialog tells you its real size may be bigger.

    FAQ

    Questions, answered.

    Windows says “Windows protected your PC”. Is Diskat safe?

    The download isn't code-signed yet, so SmartScreen warns about any new app. Click “More info”, then “Run anyway”. The full source code is on GitHub if you want to check it or build it yourself.

    macOS says it can't verify Diskat. How do I open it?

    The Mac app isn't notarized by Apple yet, so macOS blocks it the first time you open it. Close the message, open System Settings > Privacy & Security, scroll down and click “Open Anyway”. You only need to do this once.

    Is it really free? Can I use it at work?

    Yes. Diskat is open source under the MIT license, free for personal and commercial use. No ads, no accounts, no paid tier.

    Does Diskat send any data?

    No. Diskat sends nothing about you or your files. It only goes online when you ask it to check for updates, and then it just reads a small version file from diskat.cc. The only things it saves are your settings, on your own PC.

    Do I need administrator rights?

    No. Without admin rights a few protected system folders can't be read and are marked as blocked. Click “Run as Admin” if you want them counted too.

    Can I undo a delete?

    Items deleted with Del go to the Recycle Bin, so you can restore them from there. Shift+Del erases permanently and can't be undone.

    Which Windows versions are supported?

    Windows 10 and Windows 11, 64-bit. The exe is self-contained: no installer and no .NET runtime needed.

    Which Macs are supported?

    Macs with macOS 14 Sonoma or later, both Apple silicon and Intel. Open the DMG and drag Diskat to the Applications folder.
