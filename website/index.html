    Your files don't have nine lives.

    So Diskat treats every delete like it matters. These are always locked:

    C:\ C:\Windows Program Files ProgramData C:\Users\* AppData
    • 01Recycle Bin first. Del moves things to the Recycle Bin. Permanent delete needs Shift+Del and a dialog that defaults to Cancel.
    • 02Links are never followed. Junctions and symlinks are shown but never walked through, so nothing is counted twice or deleted by accident.
    • 03Tricky names are refused. Names ending in a dot or space make Windows touch a different item, so Diskat won't delete them.
    • 04Honest numbers. If a folder wasn't fully scanned, the delete dialog tells you its real size may be bigger.

    Questions, answered.

    Windows says “Windows protected your PC”. Is Diskat safe?

    The download isn't code-signed yet, so SmartScreen warns about any new app. Click “More info”, then “Run anyway”. The full source code is on GitHub if you want to check it or build it yourself.

    Is it really free? Can I use it at work?

    Yes. Diskat is open source under the MIT license, free for personal and commercial use. No ads, no accounts, no paid tier.

    Does Diskat send any data?

    No. It never connects to the internet. The only thing it saves is your language choice, on your own PC.

    Do I need administrator rights?

    No. Without admin rights a few protected system folders can't be read and are marked as blocked. Click “Run as Admin” if you want them counted too.

    Can I undo a delete?

    Items deleted with Del go to the Recycle Bin, so you can restore them from there. Shift+Del erases permanently and can't be undone.

    Which Windows versions are supported?

    Windows 10 and Windows 11, 64-bit. The exe is self-contained: no installer and no .NET runtime needed.
