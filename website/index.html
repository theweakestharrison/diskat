Features

Everything you need to free up space, nothing you don't

Point Diskat at a drive or folder. A few seconds later you know exactly where your storage went.

Parallel scanner

Many threads read folders at once with almost no memory per file. Results stream in live while it scans.

Space map

A treemap where every tile is sized by how much room it takes. Click to select, double-click to dive in.

Sorted folder tree

Heaviest first, with “% of parent” bars, file counts and dates. Sort by any column, navigate with the keyboard.

Largest files

The 500 biggest files on the whole drive in one list: old ISOs, videos, backups. Select several and delete at once.

Delete in place

Press Del to move to the Recycle Bin or Shift+Del to erase. Totals update instantly, no rescan.

Run as Admin

One click restarts Diskat elevated so protected system folders are measured too. Never elevates on its own.

Safety first

Built to never delete the wrong thing

Disk cleaners are only useful if you can trust them. Diskat is careful by default.

  • Recycle Bin by default, with a confirmation that shows the full path and size.
  • Drive roots, Windows, Program Files, ProgramData, AppData and every user profile root are locked, even through subst drives or junctions.
  • Junctions and symlinks are never followed: no double counting, no deleting through a link.
  • Warns you when a folder wasn't fully scanned, so a “0 B” folder is never a surprise.
  • Fully offline and open source: read every line of code that touches your files.

FAQ

Questions

Windows says “Windows protected your PC”. Is Diskat safe?

The download isn't code-signed yet, so SmartScreen warns about any new app. Click “More info” then “Run anyway”. The full source code is on GitHub if you want to check it or build it yourself.

Is it really free? Can I use it at work?

Yes. Diskat is free and open source, for personal and commercial use. There are no ads, accounts or paid tiers.

Does Diskat send any data?

No. It never connects to the internet. The only thing it saves is your language choice, on your own PC.

Do I need administrator rights?

No. Without admin rights a few protected system folders can't be read and are marked as blocked. Click “Run as Admin” if you want them counted too.

Can I undo a delete?

Items deleted with Del go to the Recycle Bin, so you can restore them from there. Shift+Del erases permanently and can't be undone.

Which Windows versions are supported?

Windows 10 and Windows 11, 64-bit. The exe is self-contained: no installer and no .NET runtime needed.
